# 在板读取电气安全检查

## 硬性停止条件

在完成下列检查前，**不连接 ESP 的 CS/MOSI/SCLK/MISO，不给目标 Flash 或玩具主板供电，
不按 BOOT 解锁**。允许在完全断电、放电后进行通断测量和电路追踪。
需要带电验证时，必须先查明电源轨和总线隔离方案，再单独为目标板实施受控测试，
此时 ESP 信号仍保持物理断开。

软件只读不防反灌电、短路或总线争用。ESP 上电高阻只是应用层措施，不能保证
ROM、旧固件、刷机期间或外部电路的电平。**刷 ESP 时测试夹必须完全断开。**

## 1. 辨认与记录（全部断电）

- [ ] 拍摄芯片清晰丝印，确认是 W25Q128JV，并核对完整后缀和 SOIC-8 引脚。
      不可把 1.8 V 的 JW 等型号当成 JV；128 Mbit = 16 MiB。
- [ ] 拆除玩具电池、USB、充电器及其他供电源，确认储能器件已放电。
- [ ] 用万用表确认 4 脚 GND、8 脚 VCC，测 VCC 与主板 3.3 V/STM32 VDD 是否导通；
      查明是否还有其他芯片、稳压器、充电电路或升压电路挂在该轨上。
- [ ] 逐线确认夹子触点及引脚方向，无跨脚短路；不要相信红线或夹子编号。
- [ ] 记录 STM32 的准确型号、NRST、BOOT、SPI 引脚和电源域，查其官方数据手册。
- [ ] 查明 /CS、/WP、/HOLD(/RESET) 的原板上拉与其他驱动来源。

## 2. 先确定总线能否由 ESP 独占

不能仅凭“关机”或“NRST 拉低”认定 STM32 已高阻：

- 断电的 STM32 仍可能通过 SPI 引脚保护结构反向供电。
- 共轨给 Flash 供电可能同时启动 STM32 和整块玩具主板。
- NRST 是否确实使相关引脚高阻，必须根据该 STM32 型号和实物测量确认；
  还须检查其他总线主机、外部缓冲器、上下拉及复位期间行为。
- 只测到静态电平，不能证明不存在短暂驱动或周期性访问。有条件时用示波器/
  逻辑分析仪观察 /CS、CLK、MOSI、MISO，结合器件资料确认驱动状态。
- 若采用保持 NRST 的方案，必须在目标供电之前建立有效复位，并在整个读取期间保持；
  复位控制也必须避免从 ESP GPIO 反灌电。不要在未查清电压和电路前直接连 NRST。
- 无法证明独占时，**停止在板夹读**，先隔离总线（经确认的跳线、电阻或缓冲器），
  或改用拆焊离板读取。不能靠更低频率或串电阻解决两个推挽输出相互驱动。

## 3. 选定且只保留一种目标供电

推荐顺序取决于实物测量，不能在没有原理图时固定指定：

| 方案 | 前提 |
| --- | --- |
| 原板受控供电 | 已确认 Flash 电压、总线独占、STM32 复位/隔离可靠 |
| 限流外部 3.3 V 电源 | 已确认整条轨的负载、反灌路径、共轨器件及总线状态 |
| 隔离后独立给 Flash 供电 | 隔离方式已验证，不会经信号线给断电主板反灌 |

- 不默认用 ESP 开发板 3V3 给整条玩具电源轨供电，不接 5V。
- 不同时使用原板电源、外部电源和 ESP 3V3；断电也应检查 USB/电池等隐藏供电。
- W25Q128JV 工作 VCC 范围为 2.7–3.6 V；使用稳定 3.3 V，并以芯片引脚实际测量为准。
  ESP IO 为 3.3 V，目标低于此范围、未上电或电压不兼容时禁止驱动。
- 限流值必须基于已查明的负载和上电特性设置；不在未知共轨主板上猜一个通用数值。
- 为 ESP、目标板和测量仪器建立可靠共地，确认无异常地电位差。
- 观察异常电流、发热、VCC 下陷或非预期 STM32 活动；出现任一项立即断电排查。

全部通过后：
1. 断开双方电源，连接已核对的 GND、SPI 和既定目标供电线路。
2. 重新确认夹子方向和无短路；按已验证的隔离/复位顺序上电。
3. 保持 BOOT 松开，等待应用启动（约两秒）；再按 BOOT 至少两秒并松开。
4. 从 500 kHz 开始识别和读取；不用 monitor 占用 USB 端口。
5. 完成后按受控顺序断电，断开夹子并复位 ESP，解除会话解锁状态。
   不要在 ESP 仍驱动时切断目标电源。异常退出时不能指望主机关闭必然释放信号。
